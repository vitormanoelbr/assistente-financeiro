# Regras — Agenda

- **AGENDA-001** Compromisso agendado afeta projeção, não saldo realizado.
- **AGENDA-002** Baixa de conta a pagar cria uma saída financeira real.
- **AGENDA-003** Baixa de conta a receber cria uma entrada financeira real.
- **AGENDA-004** Após baixa concluída, o compromisso original deixa de estar ativo.
- **AGENDA-005** Uma baixa gera exatamente uma movimentação financeira real.
- **AGENDA-006** Se a remoção do compromisso falhar, o sistema tenta desfazer o lançamento criado.
- **AGENDA-007** Excluir compromisso sem baixa não cria movimentação.
